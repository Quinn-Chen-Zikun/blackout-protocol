# 破晓守望 · 五大战区

## [▶ 点击开始玩](https://quinn-chen-zikun.github.io/dawnwatch/)

打开网页后，在主菜单选择战区，再点击「进入隔离区」。无需登录、下载或安装。

浏览器里的单人第一人称射击游戏。五个战区各有独立地图、灯光和路线，守住八波感染者。也可以直接用 `?map=yard|subway|tunnel|hospital|prison` 打开指定战区。

## 操作说明

也可以用浏览器打开本地的 `index.html` 游玩。

| 操作 | 按键 |
| --- | --- |
| 移动 / 冲刺 | WASD / Shift |
| 瞄准 / 射击 | 鼠标移动 / 左键 |
| 键盘瞄准 / 射击 | 方向键 / 空格 |
| 装填弹药 | R |
| 切换步枪与手枪 | 1 / 2 |
| 领取补给 | E（靠近标有十字的箱子） |
| 暂停 | Esc 或 P |

触屏用左侧摇杆移动，滑动战场瞄准。右侧按钮负责开火、装填、切枪和补给。横屏适合触屏游玩。

## 五大战区

| 战区 | 场景 | 主要区域 |
| --- | --- | --- |
| 雨夜货运港 | 室外雨夜码头，暖冷灯光与湿地反光 | 南侧闸门、中央装卸区、集装箱区、维修站、卸货仓、北侧泵站 |
| 地铁站 | 停摆列车、双侧月台与冷白灯管 | 一号站台、二号站台、停摆列车、站厅夹层、换乘通道 |
| 地下隧道 | 断电检修管廊，应急灯与滴水 | 东段 / 西段主隧道、北侧检修室、南侧排水室、中央联络段 |
| 医院 | 白绿色病区、短走廊与病房 | 东侧 / 西侧住院部、门诊走廊、中央护士站、诊疗区 |
| 监狱 | 高压探照灯下的牢房与放风场 | A 区 / B 区牢房、中央放风场、洗衣房、工场 |

每张地图都是 43 × 31 格，拥有独立的墙体、掩体、补给点和感染者出生点。波次间有 10 秒准备时间，准备期间领取的补给计入下一波。小地图显示当前位置、附近感染者和补给点。感染者出生点按实际可行走路线排序，优先选择视线外且路径合理的近处点，并避免连续重复同一处；近距离出生设有下限。

新版用 WebGL 绘制三维丧尸、湿地反光和战区光影，并按战区切换雾气、环境光和灯光布置。丧尸拥有不同的体型、步态、扑击动作和头部命中判定；场景使用混凝土、锈钢和木材的照片材质。浏览器无法使用 WebGL 时，会自动使用 Canvas 渲染。每个战区分别保存最佳波次，音效设置保存在浏览器中。

命中沿用枪焰和准星标记；爆头显示橙色「爆头」，击倒显示短暂文字和淡出光环，均不遮挡准星。

## 感染者类型

主菜单的「感染者图鉴」可以查看每类的首次出现波次和打法。

| 首次出现 | 类型 | 行为 |
| --- | --- | --- |
| 第 1 波 | 普通感染者 | 缓慢追击，靠近后用近战攻击 |
| 第 2 波 | 疾跑者 | 远快于其他类型，要优先处理 |
| 第 3 波 | 盾卫 | 实体盾牌抵挡大部分正面子弹，可以打头或绕侧后 |
| 第 4 波 | 巨化感染者 | 血量和近战伤害最高 |
| 第 5 波 | 喷吐者 | 蓄力起手时锁定酸液方向，趁蓄力横移可躲。墙和货箱也能挡住酸液 |
| 第 6 波 | 尖啸者 | 尖啸只加速能互相看见的附近感染者，短时间提高其移动速度和近战频率 |

第 7、8 波会混合六类感染者。同类喷吐者或尖啸者会错开起手。绿色箭头提示酸液，橙红三角提示尖啸。静音时也能看到预警，墙和货箱会挡住标记。
