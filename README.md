# 破晓守望 · 雨夜货运港

## [▶ 点击开始玩](https://quinn-chen-zikun.github.io/dawnwatch/)

打开网页后，点击「进入隔离区」。无需登录、下载或安装。

浏览器里的单人第一人称射击游戏。在雨夜货运港守住八波感染者。

## 操作说明

也可以用浏览器打开本地的 `index.html` 游玩。

| 操作 | 按键 |
| --- | --- |
| 移动 / 冲刺 | WASD / Shift |
| 瞄准 / 射击 | 鼠标移动 / 左键 |
| 键盘瞄准 / 射击 | 方向键 / 空格 |
| 装填弹药 | R |
| 切换步枪与手枪 | 1 / 2 |
| 领取补给 | E（靠近标有十字的箱子） |
| 暂停 | Esc 或 P |

触屏用左侧摇杆移动，滑动战场瞄准。右侧按钮负责开火、装填、切枪和补给。横屏适合触屏游玩。

## 雨夜货运港

地图为 43 × 31 格，包含南侧闸门、中央装卸区、集装箱区、维修站、卸货仓和北侧泵站。五处补给箱散布在地图上，波次间有 10 秒准备时间。准备期间领取的补给计入下一波。小地图显示当前位置、附近感染者和补给点。感染者出生点按实际可行走路线排序，优先选择视线外且路径合理的近处点，并避免连续重复同一处；近距离出生设有下限。

新版用 WebGL 绘制三维丧尸、湿地反光和港区光影。丧尸拥有不同的体型、步态、扑击动作和头部命中判定；货运港使用混凝土、锈钢和木材的照片材质。浏览器无法使用 WebGL 时，会自动使用 Canvas 渲染。最佳波次和音效设置保存在浏览器中。

命中沿用枪焰和准星标记；爆头显示橙色「爆头」，击倒显示短暂文字和淡出光环，均不遮挡准星。

## 感染者类型

主菜单的「感染者图鉴」可以查看每类的首次出现波次和打法。

| 首次出现 | 类型 | 行为 |
| --- | --- | --- |
| 第 1 波 | 普通感染者 | 缓慢追击，靠近后用近战攻击 |
| 第 2 波 | 疾跑者 | 远快于其他类型，要优先处理 |
| 第 3 波 | 盾卫 | 实体盾牌抵挡大部分正面子弹，可以打头或绕侧后 |
| 第 4 波 | 巨化感染者 | 血量和近战伤害最高 |
| 第 5 波 | 喷吐者 | 蓄力起手时锁定酸液方向，趁蓄力横移可躲。墙和货箱也能挡住酸液 |
| 第 6 波 | 尖啸者 | 尖啸只加速能互相看见的附近感染者，短时间提高其移动速度和近战频率 |

第 7、8 波会混合六类感染者。同类喷吐者或尖啸者会错开起手。绿色箭头提示酸液，橙红三角提示尖啸。静音时也能看到预警，墙和货箱会挡住标记。
