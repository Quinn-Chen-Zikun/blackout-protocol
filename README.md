# 断电协议 · Blackout Protocol

单人第一人称丧尸生存游戏。夜间货运站已被封锁，你需要守住八波感染者。

## 开始玩

下载或克隆仓库，用 Chrome、Edge 或 Safari 打开 `index.html`，点击「进入隔离区」。游戏无需安装依赖。浏览器支持鼠标锁定时，按 Esc 可暂停并释放鼠标。

| 操作 | 按键 |
| --- | --- |
| 移动 / 冲刺 | WASD / Shift |
| 瞄准 / 射击 | 鼠标移动 / 左键 |
| 键盘瞄准 / 射击 | 方向键 / 空格 |
| 装填弹药 | R |
| 切换步枪与手枪 | 1 / 2 |
| 领取补给 | E（靠近标有十字的箱子） |
| 暂停 | Esc 或 P |

触屏用左侧摇杆移动，滑动战场瞄准，右侧按钮负责开火、装填、切枪和补给。横屏视野更宽。

## 生存模式

普通感染者、疾跑感染者和重装感染者会陆续出场。利用货箱和墙壁卡住视角，观察小地图，用爆头节省弹药。每波结束有 10 秒准备时间。每个补给箱每波可领取一次，补充生命和备用弹药。准备期间领取的补给计入下一波。最佳波次和音效设置保存在浏览器中。

地图、敌人与武器画面由 Canvas 实时绘制，音效由 Web Audio 生成。原型的灵感来自《全民枪战》的丧尸生存与 CS 的鼠标瞄准和掩体对抗。
